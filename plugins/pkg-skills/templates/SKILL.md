## Refreshing this skill

Docs are a snapshot. To resync changelog/help/README without burning tokens,
execute (do not read) the bundled script:

```bash
bash scripts/sync.sh
```

It re-runs the deterministic fetcher (`pkg-skills fetch ${PKG_NAME}`) and
regenerates this skill from the fresh cache.
