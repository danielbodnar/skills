# Related Marketplaces

Other Claude Code plugin marketplaces worth adding alongside this one. Add a
marketplace with:

```
/plugin marketplace add <owner/repo>
```

| Marketplace | Repo | Notes |
|---|---|---|
| Official | [anthropics/claude-plugins-official](https://github.com/anthropics/claude-plugins-official) | Anthropic-curated: LSPs, plugin-dev, hookify, skill-creator, vendor integrations. Several of its plugins are re-exposed in this marketplace via `git-subdir` sources. |
| Community | [anthropics/claude-plugins-community](https://github.com/anthropics/claude-plugins-community) | Community-submitted plugin directory. |

Versions of cherry-picked plugins follow the upstream marketplace — entries
here are unpinned, so installs track the latest upstream commit.
